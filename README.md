# sick-day-excuse

Entry for make.fun competition **"The Funniest Sick-Day Excuse"**
(`u-zeroxfive-the-funniest-sick-day-excuse-37423a36`).

`main.ts` writes a single one-line sick-day excuse (under 200 characters)
to `(MAKEFUN_OUTPUT_DIR || "/output")/entry.txt`.

Run: `MAKEFUN_OUTPUT_DIR=/tmp/t1 node main.ts`
